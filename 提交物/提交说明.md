## 二、怎么跑起来

1. `pip install -r requirements.txt`
2. 双击 `start.bat`（Windows 一键启动）：`.env` 里配了 `AURORA_API_KEY` 走真实模型，未配自动演示模式
3. 浏览器打开 http://127.0.0.1:8000
4. 离线验证：`pytest`（156 个用例全绿，LLM 全程 mock）

## 三、演示覆盖的能力点

| 能力点 | 演示方式 |
|---|---|
| 自研 Agent Runtime，不依赖 agent 框架 | 代码 `src/aurora/runtime/`（loop / context / registry / session / trace 全部自写） |
| 四步循环：接收 → 判定 → 调工具 → 返回 | 每轮对话在 UI 上逐步展开 |
| 工具调用可视化 `name(args)` | 画面出现 `🔧 calculator(...)`、`🔧 weather(厦门)` 等 |
| 至少 3 个真实工具 | calculator / weather（Open-Meteo 实时）/ todo ×3 / read_docs 共 6 个真实工具；仅 search 为 mock |
| 多窗口独立 Session | 新建窗口 2，两窗口对话与待办互不可见 |
| 上下文记忆与追问 | 追问不重复城市名，模型仍基于上一轮天气作答且不再调用工具 |
| Trace 审计 | 右侧 Trace 面板记录每次工具调用的参数与结果 |
